# Align public cache and snapshot contracts with webpack

Unpack will align mode-dependent cache defaults, type-specific cache options, top-level configuration naming, cache naming, and effective Snapshot strategies with the observed `webpack@5.108.1` contract. The default filesystem cache uses the nearest package root's `node_modules/.cache/unpack` directory, falls back to `process.cwd()/.cache/unpack`, and uses the name `${options.name ?? "default"}-${mode}`; this supersedes ADR 0080's omitted-cache default, ADR 0099's rejection of Snapshot strategies where both timestamp and hash validation are disabled, and ADR 0111's corresponding rejection-test requirement, while expanding ADR 0079. Model-backed exclusions such as Context Module and Yarn PnP remain excluded. ADR 0138 supersedes this decision's exclusion of cache-unaffected behavior.
