# Use Rust-native webpack cache layers and item identities

Unpack will model webpack's Cache, Cache Facade, Memory Cache, idle and shutdown lifecycle, and Persistent Cache responsibilities with Rust-native interfaces owned by the Compiler, using Cache Namespace, Cache Identifier, and optional Cache ETag identity while keeping each Compilation and its graphs fresh. Resolve Records, Module Build Records, Code Generation Records, and Asset Render Records will be independent Cache Items, and resolved Build Dependency tracking that includes the Unpack toolchain supersedes the explicit-file approximation in ADR 0092; this extends ADR 0064, ADR 0085, and ADR 0095 without introducing webpack's Tapable mechanism. Each Cache Item must validate its relevant inputs, rather than relying on a whole-project Snapshot or a full Compiler-options fingerprint.
