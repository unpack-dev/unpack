# Use Rust-native webpack cache layers and item identities

Unpack will model webpack's Cache, Cache Facade, Memory Cache, idle and shutdown lifecycle, and Persistent Cache responsibilities with Rust-native interfaces owned by the Compiler, using Cache Namespace, Cache Identifier, and optional Cache ETag identity while keeping each Compilation and its graphs fresh. The shared Cache Layer seam is limited to lookup, store, and clear data-plane operations: Memory Cache owns generation retention, Persistent Cache owns preparation, access touches, restoration, and publication, and PackFile remains the lower-level Persistent Cache storage implementation. Resolve Records, Module Build Records, Code Generation Records, and Asset Render Records remain independent Cache Items that validate their relevant inputs; resolved Build Dependency tracking includes the Unpack toolchain and supersedes ADR 0092's explicit-file approximation, extending ADR 0064, ADR 0085, and ADR 0095 without introducing webpack's Tapable mechanism or a whole-project Snapshot or Compiler-options fingerprint.
