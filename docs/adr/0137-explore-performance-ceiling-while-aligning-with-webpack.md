# Explore the performance ceiling while aligning with webpack

Unpack's goal is to explore the performance ceiling of a JavaScript bundler while aligning as closely as possible with webpack's architecture and functionality. Webpack's observable bundling behavior, public JavaScript API, configuration concepts, loader and plugin model, internal naming, responsibility boundaries, and compilation flow remain the reference for that alignment. Rust-native data structures, ownership, concurrency, and other implementation techniques may be used where they preserve webpack's architectural responsibilities and observable functionality; performance gains achieved by dropping webpack functionality or replacing its architectural model do not advance this goal, and unavoidable deviations must be deliberate and documented. This decision supersedes ADR 0001.
